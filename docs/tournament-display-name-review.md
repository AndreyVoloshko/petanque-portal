## Cleanup Plan

Do not run a blind migration. Use this display change first, then clean saved names in the admin in small batches where the base name is obvious. Prioritize new and future tournaments because older names already display acceptably and may contain historical category wording that should be preserved.

For each cleanup, keep gender/category/rank in the saved base name when it describes the competition itself, and remove only year and event format words that are now generated by the UI.
